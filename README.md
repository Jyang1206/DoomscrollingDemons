# AI Video Overlay for TikTok (Built with Lynx)

## Overview

This project is an AI-powered overlay for TikTok that allows users to generate and edit videos directly from natural language prompts.
Reimagining how users interact with creative tools in the AI Era.

Users can:

- Add **timed prompts** at specific timestamps in a video.
- Generate **two video outputs** to choose from.

This creates an **AI-native, human-in-the-loop workflow** where users co-create videos with AI.

---

## Problem Statement

The rise of LLMs, agents, and AI systems is transforming how we interact with technology. From chatbots to AI-powered tools, a new wave of UI patterns is emerging to meet the demands of this AI Era.

Our project addresses this by:

- Exploring **AI-native UX patterns** such as generations, confirmations, and iterative edits.
- Leveraging **Lynx** to build UI for TikTok extensions.
- Reimagining **video creation and editing** workflows with **prompt-driven interactions**.

---

## Features

- **Prompt-based video generation**: Create videos from natural language inputs.
- **Timestamped instructions**: Insert prompts across different video moments.
- **Choice & iteration**: Get two AI-generated results to pick from.
- **Interactive editing**: Refine scenes by jumping to a timestamp and updating prompts.
- **Cross-platform support**: Built with Lynx to run across iOS, Android, and Web.

---

## AI era relevance

- Human-in-the-loop: Users are part of the creative process of drafting the video and collaborating with AI rather than just consuming it.
- Multiple generations: There are multiple video options to pick from.
- Agent confirmation modal: The AI will clarify what it plans on doing and ask the user for permission to proceed so that it is an assistant, not a blackbox.
